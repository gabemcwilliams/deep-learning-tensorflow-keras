## Deep Learning with TensorFlow and Keras

This repository showcases deep learning projects and experiments implemented using TensorFlow and Keras. It covers both foundational and intermediate neural network architectures, including CNNs, RNNs, GANs, and Autoencoders, along with applied NLP and regression tasks. Each notebook is structured for clarity and educational value, with outputs and comments included.

### Notebooks Included

- `autoencoders_blobs.ipynb` — Dimensionality reduction via autoencoders on synthetic datasets.
- `classification_cancer_cells.ipynb` — Binary classification of cell samples using dense neural networks.
- `cnn_fashion_mnist_cleaned.ipynb` — Convolutional neural network trained on the Fashion MNIST dataset.
- `cnn_on_cifar_10.ipynb` — Image classification using deep CNNs on CIFAR-10.
- `dnn_kc_house_regressions.ipynb` — Dense regression model for King County housing data.
- `dnn_lending_club.ipynb` — Loan risk classification using fully connected networks.
- `gan_conv2d_refactored.ipynb` — A convolutional GAN generating handwritten digit '0' images.
- `gan_mnist.ipynb` — A basic GAN with dense layers, trained on MNIST zeros.
- `gutenberg_author_scraper_export.ipynb` — Scrapes and processes Project Gutenberg texts for NLP training.
- `loss_curve_viz.ipynb` — Visualizing loss and accuracy trends over training epochs.
- `mnist_cnn_cleaned.ipynb` — Cleanly implemented CNN for MNIST digit classification.
- `nlp_with_rnn_poe.ipynb` — RNN-based language modeling on Edgar Allan Poe's corpus.
- `regression_kc_house_eda.ipynb` — Exploratory data analysis and regression prep for housing prices.
- `rnn_frozen_desert_forcasting.ipynb` — Forecasting frozen dessert demand with RNNs.
- `rnn_sine_wave_forcasting.ipynb` — Sequence prediction on synthetic sine wave data.

### Folder Structure

All content resides under the `notebooks/` directory. Each file is a standalone Jupyter notebook, and most can be run directly after installing dependencies from `requirements.txt`.
